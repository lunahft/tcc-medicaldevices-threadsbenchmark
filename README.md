# Hospital Telemetry System

Backend Java para ingestão e processamento concorrente de dados de
telemetria fisiológica de múltiplos pacientes hospitalares.

O sistema será utilizado como ambiente experimental para comparação
entre Platform Threads e Virtual Threads em Java.

## Status

Modulo telemetry-core criado. 
Modulo telemetry-api criado.

Desenvolvimento do repositorio em PostgreSQL.
